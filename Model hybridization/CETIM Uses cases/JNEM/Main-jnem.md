-  Fault detection (how database is created)
	- Decision Tree
	- 1d sim is used to create a database for creating databaswe
	- using samples of the control vector operation space
	- At each of the operating points, one or more values of the component vector are increased or reduced from the nominal point
	- the measured process vector is recorded as well as the index, n, of the changed parameter(s).
	- a ML algorithm (Decision Tree) is then learned to estimated the changed indexes 
	- Explanation: Vector control space are samples. For each combination, one or more parameter(s) of nominal parameters are increased or decreased, then we obtain a new parameters vector (vector components) which is used to simulate the vector process

- Fault estimation
	- LS-SVR
	- this database is only generated immediately after the localization step is completed.
	- « database is generated by the 1D model at the specific control vector values extracted from the real system and using 20 evenly spaced variations of the specific component value, in order to store the resulting process vector. » (Imhogiemhe et al., p. 4)
	- Explanation: A specific (real) vector control is used, parameters (vector components) which index(es) are infered by Fault detection are used to generate a new vector components by sampling over their space. For each combination, the process vector is simulated with the obtained vector component.
